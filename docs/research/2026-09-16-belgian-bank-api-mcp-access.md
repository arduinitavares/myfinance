# Belgian bank API / MCP access (public research, 2026-09-16)

**Scope.** Public, official-source research for a single-person local finance project. No credentials, authenticated calls, personal data, or provider contact was used. “MCP” means a documented official Model Context Protocol server, not a generic connector or browser automation.

## Preliminary recommendation

For 2026 syncing, pilot **Enable Banking’s personal API path first**; it documents free personal use for a private individual’s own linked accounts. Treat **BankSync as a paid, provider-hosted MCP candidate**. A working bank UI login is a separate entitlement from arbitrary API access. No official Belfius or Beobank MCP server was found in the banks’ public documentation searched; this is “no official documented MCP found,” not proof that none exists privately. No accounts were connected during this research.

## Belfius

* **Official API:** Belfius publishes a live PSD2 AIS API for account balances and booked transaction history, plus PIS and CAF APIs. Production access is granted only to a TPP authorised under PSD2; Belfius says the TPP must be recognised by its competent authority and provide eIDAS QWAC and QSeal certificates. The customer authenticates through a Belfius redirect/consent flow, after which the TPP receives access/refresh tokens. [Belfius Get Started](https://developer.belfius.be/devportal/en/getstarted/index.aspx) [Belfius AIS marketplace](https://developer.belfius.be/devportal/en/apis/accounts/index.aspx) [Belfius support: AIS eligibility](https://developer.belfius.be/devportal/en/support/index.aspx)
* **What it covers:** The published AIS endpoints are for Belfius **payment accounts**, balances, account details, and booked transactions. The API reference describes the account identifier as an encrypted logical ID mapped to an IBAN. [Belfius account API reference](https://developer.belfius.be/devportal/en/apis/accounts/reference.aspx)
* **Historical lookback:** Belfius says the underlying channel history can reach almost 10 years, subject to when the account opened. The default TPP window is 90 days. Older transactions require a date range and strong customer authentication (SCA); after the last authentication, transaction access must be renewed after 180 days. [Belfius AIS FAQ](https://developer.belfius.be/devportal/en/apis/accounts/FAQ.aspx) [Belfius AIS flows](https://developer.belfius.be/devportal/en/apis/accounts/flows.aspx)
* **Cards:** The AIS documentation is scoped to payment accounts and booked account transactions. It does not document a general credit-card purchase/statement API. Belfius has a customer-facing credit-card transaction/statement page, but that UI does not establish an API entitlement. [Belfius credit-card transactions](https://www.belfius.be/webapps/fr/selfcare/belfius/cartescredit/releves)

## Beobank

* **Official API:** Beobank’s official Open Banking PSD2 page says its REST API (STET v1.4) serves TPPs: AISP account information and transactions, PISP payment initiation, and CBPII funds-availability checks. It invites TPP developers to consult technical documentation and request sandbox access. [Beobank Open Banking PSD2 (NL)](https://www.beobank.be/nl/openbanking.html) [Beobank Open Banking PSD2 (FR)](https://www.beobank.be/fr/openbanking.html)
* **Who can use it:** The page expressly frames access as third-party payment-service providers under PSD2, not as a self-service API for an individual account holder. Beobank also says it obtained a Belgian National Bank exemption from having to provide a contingency mechanism such as screen scraping/reverse engineering. Therefore, a local app should assume it needs an authorised TPP/AISP path; the public page does not document direct individual developer onboarding, certificate prerequisites, token flow, or production approval criteria.
* **Historical lookback:** No Beobank public official page located in this search states a transaction-history lookback period or re-authentication interval. Treat the limit as **unknown** until the bank’s TPP technical documentation or an authorised intermediary documents it.
* **Credit cards:** Beobank separately documents credit-card transaction views and online statements in Beobank Online/Mobile. Its customer agreement says online credit-card statements remain available for ten years after activation, but that is a user-interface/document-retention rule, not evidence of PSD2 API access or an export API. [Beobank card management](https://www.beobank.be/nl/betalen/kredietkaarten/mijn-kaart-beheren.html) [Beobank Online/Mobile agreement](https://www.beobank.be/sites/default/files/2022-06/202211_BBOL_Convention%20Beobank%20Online%20et%20Beobank%20Mobile_EN.pdf)

## Provider paths (separate from bank-owned MCP)

* **Enable Banking:** Its terms document free Control Panel/API use and permit production personal/private-individual use for the individual’s own linked accounts. Its linked-accounts documentation separates account activation from API authorization. Its December 2025 changelog lists maintained Belfius and Beobank integrations. [Terms](https://enablebanking.com/terms/) [Linked accounts](https://enablebanking.com/docs/api/linked-accounts) [December 2025 changelog](https://enablebanking.com/blog/2026/01/15/enable-banking-changelog-december-2025)
* **Historical caution:** Enable Banking’s FAQ says full history may be available only shortly after authorization (often about one hour for many banks), then generally 90 days; this is not a Belfius- or Beobank-specific guarantee. [Enable Banking FAQ](https://enablebanking.com/docs/faq/)
* **BankSync:** BankSync publicly lists both Belfius and Beobank for Belgium in beta and identifies Salt Edge as the route. It advertises a hosted MCP endpoint (`https://mcp.banksync.io`) and says its MCP exposes the same data as its REST API. Its pricing FAQ lists Standard at $7/month or $6/month annual-equivalent with five banks and daily sync. Treat coverage, card history, and current quotas as provider claims to verify at pilot/checkout time. [Belgium coverage](https://banksync.io/be) [MCP](https://banksync.io/product/mcp) [Pricing](https://banksync.io/pricing)

## Decision for MyFinance

An MCP connection can be bank-owned or provider-hosted. The bank-owned production path still requires the bank’s PSD2/TPP controls; Enable Banking offers a documented personal API route, while BankSync advertises a hosted MCP route. For card purchases/statements, intermediary support remains unproven. The bank’s own UI can remain a manual/local import source. Confirm product coverage, history limits, and checkout quotas before designing the sync contract.
