# Repository change quality contract

Changes reach `main` through an issue-linked `dev/<slug>` branch and focused pull request, merging only after required checks pass. The canonical Python gate remains `pyrepo-check --all`, configured to cover all repository-owned Python while excluding environments, dependencies, generated files, worktrees, and test code from Bandit's runtime-security scope; application code and tests remain subject to Ruff, annotation, `ty`, and pytest checks, and owned code may not use `noqa`, `type: ignore`, `nosec`, disabled rules, or configuration suppressions instead of fixing findings. The frontend gate remains `npm ci`, `npm run test:ci`, `npm run build`, and `npm run check:bundle`, with no ignored failures or build warnings and no additional tooling until these checks prove insufficient. Non-trivial behavior changes and bug fixes begin with the smallest focused failing test, bank adapters use only sanitized or synthetic fixtures, and tests target the lowest useful layer without an arbitrary coverage-percentage target.
