# First-class movement chains

MyFinance persists Movement Chains as part of the Consolidated Financial Record instead of reconstructing connections only when producing reports. A chain may combine Credit Draws, Transfers, currency conversions, Debt Repayments, and Financial Costs; Event Allocations let it split, merge, or represent partial settlement without duplicating source evidence. This allows the Operator to trace origin, destination, completeness, and end-to-end cost while preserving uncertainty when Source Records do not support a definitive connection.
