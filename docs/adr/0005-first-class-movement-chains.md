# First-class movement chains

MyFinance persists Movement Chains as part of the Consolidated Financial Record instead of reconstructing connections only when producing reports. A chain may combine Credit Draws, Transfers, currency conversions, Debt Repayments, and Financial Costs; Event Allocations let it split, merge, or represent partial settlement without duplicating source evidence. Chains are used only when a connection prevents false Income, duplicate or missing Expenses, or missing Financial Costs, and they preserve uncertainty when Source Records do not support a definitive connection. They do not create a transfer-route analytics feature.
