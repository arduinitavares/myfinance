# Local-first, private transaction classification

MyFinance runs local similarity before considering an external LLM and sends nothing externally without the Operator's explicit confirmation. Any external request contains only the minimum sanitized description and classification fields needed, excluding account and card numbers, IBANs, references, personal identifiers, full Source Records, and raw statement text; prompts and raw financial descriptions are not logged, model output is treated as untrusted, and it remains a Classification Proposal until the Operator approves it. Confirmed classifications update the local similarity index and prefill future proposals, but neither future imports nor historical records change silently, and batch application always previews the exact candidates for Operator selection and confirmation.
