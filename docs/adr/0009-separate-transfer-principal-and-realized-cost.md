# Separate transfer principal and realized cost

MyFinance never treats principal moved inside the Financial Perimeter as a cost. Each Movement Chain reports Explicit Costs such as fees, taxes, interest, and penalties separately from Exchange-Rate Cost measured by comparing the provider's Applied Rate with an independent Reference Rate, then combines them as Realized Cost without double-counting. The Applied Rate comes from Source Records when stated or is derived from linked source and destination amounts; until either is available, the chain is Cost Pending rather than assigned a false zero. The first version uses the existing daily ECB EUR-based rates for EUR, USD, and BRL; it retains the source, date, rate, and selection basis so transfer-related costs enter Expense totals without principal being counted as spending.
